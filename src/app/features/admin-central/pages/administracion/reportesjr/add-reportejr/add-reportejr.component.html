El JRXML contiene la consulta SQL; el backend la ejecuta con los parámetros del reporte. El backend prepara una lista de objetos Java (Beans) y Jasper utiliza sus propiedades como campos. El frontend envía una lista de datos al backend para generar el documento.
¿Qué método debo elegir?

El método indica de dónde obtiene Jasper los datos que mostrará.

MétodoOrigen de los datosCuándo usarlo
1. SQL directoLa consulta está en el JRXML y el backend la ejecuta en la base de datos.Consultas de cobros, emisiones, saldos o trámites. Ejemplo: RubrosCobrados recibe fechas y consulta los cobros.
2. Conjunto de BeansEl backend prepara una lista de objetos Java y Jasper lee sus propiedades.Cuando necesitas calcular, combinar o transformar datos con lógica Java antes de imprimir.
3. Desde el frontendLa pantalla envía una lista de datos al backend, que genera el reporte.Para imprimir datos preparados o seleccionados en una pantalla.

Parámetros: los tres métodos pueden recibir información adicional, como fechas, ID de usuario, título o número de factura.

Al elegir: verifica cómo el módulo consumidor entrega los datos. Una plantilla sin SQL puede usar Beans o datos del frontend. Cambiar este selector requiere que esa integración corresponda al método elegido.
